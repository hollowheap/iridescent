# Iridescent Loop

## Entrypoints

- New workspace without `AGENTS.md`: `{{skill:init}}`
- Broken layout, legacy `artifacts/`, or failed graph checks: `{{skill:doctor-iridescent}}`
- Single-file reversible edit: `{{skill:implement}}` (Quick change)

## Delivery Loop

1. `{{skill:brainstorm}}` — frame destination, research primary sources, compare 2-3 archetypes, emit `.artifacts/BRAINSTORM.md`.
2. `{{skill:design}}` — convert outcomes to `Rxx`, resolve unknowns via the question tool, record accepted `Dxx`, update `.artifacts/ARCHITECTURE.md`.
3. `{{skill:specify}}` — turn accepted `Dxx` into boundary invariants `Sxx` in `.artifacts/SPECS.md`.
4. `{{skill:plan}}` — break `Sxx` into atomic vertical tasks `Txx` in `.artifacts/TASKS.md`.
5. `{{skill:implement}}` — execute `Txx` test-first and hand off review.
6. `{{skill:review}}` — run `diff`, `slice`, `seam`, or `robust` review after implementation.
7. `{{skill:update}}` — reconcile RDST artifacts and `.artifacts/CONTEXT.md` with current code.
